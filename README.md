<summary><b>🎬 Movie / Book Recommendation System</b></summary>
<br/>

A collaborative, team-built recommendation engine suggesting movies and books using **content-based and collaborative filtering** techniques, developed as an AI/ML group project over roughly a four-month build cycle.

| | |
|---|---|
| **Stack** | Python, Machine Learning (Content-Based + Collaborative Filtering) |
| **Scale** | 5-member engineering team |
| **Performance** | Iteratively tuned recommendation accuracy across both filtering approaches |
| **Security** | Standard data-handling practices for user preference data |
| **Impact** | Delivered as a full AI/ML mini-project demonstrating applied recommender systems |
| **Repository** | _Add repo link once published_ |

This project combines two recommendation paradigms to balance personalization with discoverability — content-based filtering surfaces items similar to what a user already likes, while collaborative filtering brings in patterns from similar users, giving the system more well-rounded suggestions.

</details>

| | |

| **Scale** | Individual / college demo project |
| **Performance** | Real-time-style coordinate updates along a simulated route |
| **Security** | N/A — simulated data, no live user tracking |
| **Impact** | Demonstrates location-tracking system design without hardware dependencies |
| **Repository** | _Add repo link once published_ |

This approach lets the tracking logic, map rendering, and update pipeline be fully validated in a demo environment before any real GPS hardware is introduced.
